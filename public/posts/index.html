How I Built This Blog

 Posted on March 7, 2026  |  Rob Derickson

Create a GitHub repository

  1. Create a new GitHub repository named <user name>.github.io where <user name> is your GitHub user name.
  2. Clone the new repository.

Install Hugo

NOTE: Since I built this on Fedora 64-bit, so I’ll include instructions for that. See Hugo’s installation instructions for your operating system.

  1. Download a Hugo release for your operating system from Hugo’s releases on GitHub. I downloaded hugo_<version>_linux-amd64.tar.gz
  2. Extract the Hugo binary: 
    tar -xtvf ./hugo_<version>_linux-amd64.tar.gz
  3. Move the binary to /usr/local/bin: 
    mv ./hugo /usr/local/bin/
  4. Make the binary executable: 
    chmod +x /usr/local/bin/hugo

Create a new Hugo site and install a theme

  1. In the parent directory containing your <user name>.github.io repository, create a new site: 
    hugo new site <username>.github.com --force
    NOTE: The --force option is required because a folder named <user name>.github.io already exists.
  2. Check out Hugo themes gallery to select a theme you like. I’m using the Paper theme.
  3. Set your location to your repository directory and add the chosen theme as a submodule in your repository. 
    cd ./<user name>.github.io
git submodule add https://github.com/halogenica/beautifulhugo.git themes/beautifulhugo
  4. Update hugo.toml to include a key for your theme. 
    echo "theme = 'beautifulhugo'" >> hugo.toml
  5. Start the Hugo server and browse to http://localhost:1313 to confirm it is working. 
    hugo server
